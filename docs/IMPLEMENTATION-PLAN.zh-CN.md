# 授权平台实施计划

## 决策

以 Keygate 为授权服务端和管理后台，保留其 AGPL v3 署名要求。AutoMate 通过自有适配层调用公开激活接口，避免客户端直接依赖管理后台实现细节。

旧 KamiCloud、xxgkami 和 OpenClaw 测试部署已删除；正式授权服务统一使用 Lucas License（Keygate 衍生版）。

- [x] 增加制卡批次表，并在许可证上记录批次。
- [x] 增加批量制卡管理接口，数量限制 1–5,000。
- [x] 后台增加批量制卡入口和 TXT/CSV 下载。
- [x] 批量生成的卡密允许没有客户邮箱。
- [x] 月卡/年卡在首次激活时原子写入起止时间。
- [x] 永久卡签名令牌无时间过期；时长卡令牌到许可证到期时失效。
- [x] 增加服务端单元测试代码并通过前端类型检查和生产构建。

## 验收标准

1. 一次可生成并下载至少 1,000 张互不重复的卡密。
2. 未激活月卡不消耗有效期，首次激活后得到完整 30 天。
3. 同一卡密不能超过套餐设备数。
4. 月卡令牌离线可用至到期，永久卡在断网和服务端停机时仍可启动。
5. 数据库泄漏时无法直接伪造新许可证；客户端泄漏时无法得到签名私钥。
6. 日常销售只需要“生成批次、导出、导入发卡平台”三步，无需逐单操作。

## 当前验收结论（2026-08-11）

- 服务端全部 Go 测试、前端类型检查和生产构建通过。
- 全新 PostgreSQL 数据库成功执行 22 个迁移并完成首次初始化。
- 实际生成 1,000 张卡密，接口返回、TXT 导出均为 1,000 张且无重复，耗时约 1.6 秒。
- 月卡令牌期限精确为 2,592,000 秒（30 天），年卡为 31,536,000 秒（365 天）；同机重复激活返回 `already_activated`，第二设备返回 `ACTIVATION_LIMIT`。
- 永久令牌 `exp=0`；关闭 Keygate 服务后，AutoMate 仍能本地验签月卡和永久令牌。
- AutoMate 会拒绝错误产品、错误设备和被篡改签名的令牌。
- Cloudflare Tunnel 公网 HTTPS 健康检查通过，客户端在大陆网络可完成首次激活。
- 正式永久卡已通过 AutoMate 真实激活、AES-GCM 本地保存、断网重启和严格 Base64URL 篡改拒绝验收。
- 三张生产测试卡在验收结束后均已撤销。
- 详细记录见 `docs/VALIDATION-REPORT.zh-CN.md`。
